==== 11.6.2 User control of accessibility features

____
[.BLOCK_LANG_EN]
--
Where ICT is, or includes, platform software,
the platform software shall provide sufficient modes of operation for user control over documented platform
accessibility features.

NOTE: 
Clause 12.3 specifies that accessibility features of the ICT are to be documented either as part of the ICT
or in a separate documentation.
--
